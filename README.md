## How do i run it through NPM?

First, install NPM, if you're on Windows, you can download it through here:
https://docs.npmjs.com/downloading-and-installing-node-js-and-npm

If you're on Linux, you can download it via Terminal:
 `sudo apt update sudo apt install nodejs npm`

After that, go to the project root folder and run:
`npm install`

After its done installing, run:
`npm run dev`

It will be available in: http://localhost:5173/
